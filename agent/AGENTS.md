# AGENTS.md

## About this project

`calc` is a tiny Python library. Production code lives in `src/`, tests in `tests/`.

## Conventions

- Record every user-visible change as a bullet under `## Unreleased` in `CHANGELOG.md`. Name the function you changed.
- Run the tests with `python -m pytest`.

## Canary
